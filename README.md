SAP MM Project
Project Overview
This project demonstrates the configuration and implementation of the SAP Materials Management (SAP MM) module, focusing on the Procure-to-Pay (P2P) cycle.
The project covers essential procurement processes, organizational structure configuration, and inventory management activities in SAP.
Project Objectives
- Understand SAP MM organizational structure.
- Configure company codes, plants, and storage locations.
- Understand and execute the Procure-to-Pay cycle.
- Practice procurement and inventory management transactions.
- Understand integration between SAP MM and SAP FI.
Key Topics Covered
- Enterprise Structure Configuration
- Material Master and Material Groups
- Purchasing Information Records
- Purchase Requisition (PR)
- Request for Quotation (RFQ)
- Purchase Order (PO)
- Goods Receipt (GR)
- Invoice Verification (MIRO)
- Release Strategy
- Inventory Management
- SAP MM–FI Integration
Procure-to-Pay Cycle
1. Purchase Requisition (PR)
2. Request for Quotation (RFQ)
3. Vendor Quotation
4. Purchase Order (PO)
5. Goods Receipt (GR)
6. Invoice Verification (MIRO)
7. Vendor Payment
Tools and Technologies
- SAP S/4HANA / SAP MM
- SAP GUI
- Microsoft Word (Project Documentation)
Learning Outcomes
Through this project, I gained practical knowledge of SAP MM configuration, procurement processes, inventory management, and integration with other SAP modules.
